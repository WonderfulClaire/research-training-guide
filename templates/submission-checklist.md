# 投稿前检查清单（会议 / 期刊通用）

> 投稿前逐条打钩。很多 desk reject 就死在这些低级但致命的问题上。配合 [03 会议论文](../docs/03-conference-paper.md) 与 [04 期刊论文](../docs/04-journal-paper.md)。

## 一、内容与逻辑
- [ ] 标题含"方法 + 任务 + 亮点"，一眼看懂做什么。
- [ ] 摘要 5 句骨架完整，最硬的数字已前置。
- [ ] 引言用编号列出 3–4 条贡献，每条正文有证据。
- [ ] 相关工作按"路线"分组，点明与本文不同。
- [ ] 方法有形式化 + 总览图 + 逐模块直觉解释。
- [ ] 摘要/引言承诺的结果，正文都兑现了（无过度声明）。

## 二、实验与数据
- [ ] Baseline 公平（相同数据/协议），覆盖近 3 年 SOTA + 经典。
- [ ] 数据集为公认公开集，划分严格隔离（test 不参与调参）。
- [ ] 指标为领域公认并给出定义/引用。
- [ ] 关键创新点都有对应消融。
- [ ] 多种子运行，报均值±方差（非单次运气值）。
- [ ] （如适用）报告了参数量/时延/RTF 等效率指标。

## 三、图表
- [ ] 所有图矢量优先（PDF/EPS），位图 ≥ 300 dpi，清晰可读。
- [ ] 图表在正文都有引用与解释，编号连续。
- [ ] 主结果表加粗最优值，单位/符号一致。

## 四、格式与规范
- [ ] 用**官方模板**（如 IEEEtran），未手动改字号/行距。
- [ ] 未超页（会议尤其硬性，如 ICASSP 4 页）。
- [ ] 参考文献完整可检索，正文引用与列表一致，无孤儿引用/缺失。
- [ ] （会议 IEEE）PDF 已过 **PDF eXpress** 校验（字体嵌入、无异常元数据）。

## 五、双盲（如适用）
- [ ] 正文、页眉、脚注、致谢无作者/机构信息。
- [ ] 引用自己用匿名编号，不写 "our prior work"。
- [ ] PDF 元数据里无作者名。
- [ ] arXiv 预印本未附可识别链接。

## 六、语言与润色
- [ ] 全文过一遍拼写/语法（Grammarly 等）。
- [ ] 时态一致（背景现在时、工作过去/现在时）。
- [ ] 避免中式英语与口语词，术语全文统一。
- [ ] （期刊，建议）母语者或专业润色再过一遍。

## 七、专利协同（如成果有产业价值）
- [ ] 已评估是否申请专利。
- [ ] 若要申专利，**已先占申请日再投稿**（避免论文公开破坏新颖性）。

## 八、提交材料
- [ ] Cover Letter（期刊）：说清贡献、适配性、无一稿多投与利益冲突声明。
- [ ] 补充材料 / 代码链接（如要求）准备就绪。
- [ ] 作者信息、通讯作者、基金致谢（终稿）填写正确。
- [ ] 选对了投稿类别/track 与目标 venue。
