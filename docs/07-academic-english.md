# 07 · 学术英语与句式库

> 直接抄就能用的高频句式，按写作场景分类。**时态原则**：背景/事实用现在时，你做的工作用过去时或现在时，公认结论用现在时。

## 提出研究动机

- *Recently, ... has attracted considerable attention due to its wide applications in ...*（近年……因在……中的广泛应用而备受关注）
- *... is a fundamental problem in signal processing with both theoretical and practical significance.*（……是信号处理中的基础问题，兼具理论与实际意义）
- *... plays a crucial role in ..., yet remains challenging under ... conditions.*（……在……中起关键作用，但在……条件下仍具挑战）

## 指出已有方法的不足（找 gap）

- *However, these methods often suffer from ..., limiting their use in ...*（然而这些方法常受……困扰，限制了在……中的应用）
- *A major limitation of prior work is that ..., which leads to ...*（已有工作的一个主要局限是……，这导致……）
- *Despite their success, existing approaches struggle to ... when ...*（尽管取得成功，现有方法在……时难以……）

## 陈述本文贡献

- *In this paper, we propose ..., a novel framework that ...*（本文提出……，一个新颖的框架，用于……）
- *The key advantage of our approach is ..., enabling ...*（我们方法的关键优势是……，从而实现……）
- *The main contributions of this work are summarized as follows: (i) ...; (ii) ...; (iii) ...*（本文主要贡献如下：……）

## 描述方法

- *We formulate the problem as ..., where ... denotes ...*（我们将问题形式化为……，其中……表示……）
- *Let x ∈ R^T denote the observed signal; our goal is to estimate s from x.*（设 x 为观测信号，目标是从 x 估计 s）
- *Specifically, the module takes ... as input and produces ...*（具体地，该模块以……为输入，生成……）
- *Intuitively, this design allows the network to focus on ...*（直观上，该设计使网络能关注……）

## 报告实验结果

- *Experimental results demonstrate that our method achieves ..., outperforming ... by ...*（实验表明我们的方法达到……，比……高出……）
- *As shown in Table 1, the proposed method consistently outperforms all baselines.*（如表1所示，所提方法稳定优于所有基线）
- *An ablation study further confirms that each component contributes to ...*（消融实验进一步证实每个组件都对……有贡献）
- *These results indicate / suggest that ...*（这些结果表明……）

## 讨论与分析

- *One possible explanation for this behavior is that ...*（对此现象一种可能的解释是……）
- *Interestingly, we observe that ..., which we attribute to ...*（有趣的是，我们观察到……，我们将其归因于……）
- *This is consistent with / in contrast to the findings of [X].*（这与 [X] 的发现一致/相反）

## 结论

- *We presented ..., which achieves ... . Future work will explore ...*（我们提出了……，取得……。未来工作将探索……）
- *In summary, this work demonstrates that ..., opening up new possibilities for ...*（总之，本文证明了……，为……开辟了新可能）

## 连接与过渡词（避免全文都是 and / but）

| 关系 | 可用词 |
|---|---|
| 递进 | Furthermore, Moreover, In addition, Besides |
| 对比 | In contrast, However, Nevertheless, On the other hand |
| 因果 | Consequently, Therefore, As a result, Hence |
| 强调 | Notably, In particular, Importantly, Remarkably |
| 举例 | For instance, Specifically, e.g., namely |
| 总结 | In summary, Overall, To conclude, In brief |

## ⚠️ 中式英语常见坑

1. **滥用 can / may**：学术写作中"能力"用 *is able to*，"可能"用 *is likely to*。
2. **动词名词化不够**：*we improve the performance* 不如 *we achieve improved performance*（更学术、更客观）。
3. **口语词**：避免 *very / a lot of / get / thing*，换成 *significantly / numerous / obtain / factor*。
4. **主语过度用 we**：适当用被动或以研究对象作主语（*The model is trained on …*）。
5. **冠词与单复数**：中文没有冠词，写完务必检查 a/an/the 与单复数一致。
