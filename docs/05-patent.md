# 05 · 专利写作

> 很多科研人把专利当"中文论文"写，结果被驳回。专利和论文的**目标、语言、公开策略完全不同**。先理解本质，再动笔。本章以中国发明专利为主，原理对多数法域相通。

## 一、专利和论文根本不是一回事

| 维度 | 学术论文 | 专利 |
|---|---|---|
| **目标** | 传播知识、证明正确性 | 圈定独占权、防别人做 |
| **公开程度** | 充分公开细节便于复现 | 公开到"本领域人员能实现"即可，核心留余地 |
| **语言** | 追求新颖表达、强调贡献 | 追求**上位、涵盖广**、用词严谨一致 |
| **评价** | 同行评审（双盲） | 审查员依"三性"审查 |
| **时效** | 越快发表越好 | **先占申请日，再考虑公开** |

> 一句话：论文是"讲清楚、讲透"，专利是"圈得宽、守得住"。

## 二、三种专利类型

| 类型 | 保护对象 | 审查/周期 | 典型场景 |
|---|---|---|---|
| **发明专利** | 产品/方法/工艺（技术方案） | 实质审查，约 2–3 年 | 核心算法、系统设计 |
| **实用新型** | 产品的形状/构造 | 初步审查，约 6–12 个月 | 硬件结构、装置 |
| **外观设计** | 产品外形/图案 | 初步审查 | UI、工业品外观 |

算法/模型类成果，通常走**发明专利**（写成"一种基于……的方法/系统"）。

## 三、授权三性（核心门槛）

- **新颖性**：申请日之前，没有同样的发明被公开发表、公开使用或以其它方式为公众所知。
- **创造性**：与现有技术相比，有"突出的实质性特点"和"显著的进步"（非显而易见）。
- **实用性**：能够制造或使用，并产生积极效果（能落地，不是纯理论）。

## 四、⚠️ 致命顺序问题：论文发表会破坏新颖性

**这是科研人最容易踩、且不可逆的坑：**

> 如果你的算法先发了会议/期刊论文（含 arXiv 预印本），再想申请专利，会因"已公开、丧失新颖性"被驳回。

**正确策略：**
1. **先申请专利**（或至少提交以抢占申请日），拿到申请号后再投稿论文；
2. 或用**优先权**在首次申请日起 12 个月内衔接后续布局。

论文和专利可以"同源"：**同一套技术，论文讲深讲透（学术影响力），专利讲宽讲稳（保护）**。但**申请日必须早于论文公开日**。动笔投稿前，先问一句："这个要不要申专利？"

## 五、专利文件结构（中国发明专利）

一份申请主要包含：请求书、权利要求书、说明书（含摘要）。

| 部分 | 作用 | 写法要点 |
|---|---|---|
| **请求书** | 基本信息 | 发明名称、申请人、发明人、优先权。名称要体现技术方案，如"一种基于XX的语音增强方法"。 |
| **权利要求书**（最重要）| 法律保护范围 | 用技术特征限定保护边界。独立权利要求定最大范围，从属权利要求层层兜底。 |
| 说明书 · 技术领域 | 一句话 | 本发明所属的技术领域。 |
| 说明书 · 背景技术 | 铺垫 | 描述现有技术的状况与不足，引出要解决的问题（为"创造性"铺垫）。 |
| 说明书 · 发明内容 | 核心 | 要解决的技术问题、技术方案要点、有益效果。 |
| 说明书 · 附图说明 | 看图说话 | 对每张附图一句话说明（"图1为本发明方法流程图"）。 |
| 说明书 · 具体实施方式 | 最详细 | 结合附图举多个例子，讲到"本领域普通技术人员能实现"。 |
| 说明书摘要 + 摘要附图 | 检索用 | 200 字内概括技术方案与要点，附一张代表性图。 |

> **权利要求是"圈地"，说明书是"地基"。** 权利要求里每个特征，说明书里都要有支持（否则以"不支持"被驳回）。先想清楚要圈多大，再回头写厚说明书。

## 六、权利要求撰写：专利的"命根子"

写窄了保护不够，写宽了易被驳回或不稳定。

### 独立 vs 从属

| 独立权利要求 | 从属权利要求 |
|---|---|
| "前序部分 + 特征部分"结构 | 引用在前的权利要求，补充附加特征 |
| 只写**必要技术特征**，可省的都下放 | 层层设防：大范围被无效时，小范围仍能保住 |
| 范围尽量**上位**（用"模块/单元"而非具体品牌） | 多写几条，提高稳定性 |

### 撰写套路（方法类示例）

```
1. 一种基于XX的语音增强方法，其特征在于，包括以下步骤：
   步骤S1：获取带噪语音信号，并进行分帧处理；
   步骤S2：利用训练好的神经网络模型，对所述分帧信号进行……；
   步骤S3：根据……重构得到增强语音。
2. 根据权利要求1所述的方法，其特征在于，所述步骤S2中……。
3. 根据权利要求1所述的方法，其特征在于，还包括……。
```

### 五个关键技巧

1. **上位概念**：用"特征提取模块"而非"MFCC模块"，用"终端"而非"手机"，扩大覆盖。
2. **必要特征最小化**：独立权项只放"缺它就不能解决问题"的特征，其余放从属。
3. **用词一致**：同一事物全文用同一名词，别一会儿"网络"一会儿"模型"。
4. **功能性限定要谨慎**：过多"用于……的模块"会被要求结合说明书解释，适当用结构描述。
5. **支持性**：权项每个特征都需在说明书具体实施方式中有对应记载。

> **和论文表达的反差**：论文写"用 ResNet-18 提取特征"（具体、可复现）；专利写"利用深度神经网络进行特征提取"（上位、圈地）。前者是公开，后者是保护。

**记忆口诀**：*权项圈地要宽，说明书地基要厚，二者特征要对得上。*

## 七、申请流程（中国发明专利，简化）

```
技术交底 → (找代理机构/自撰) 撰写申请文件 → 提交申请、获得申请日与申请号
  → 初步审查 → (18个月) 公开 → 请求实质审查 → 实审(可能多次答复审查意见OA)
  → 授权 或 驳回(可复审)
```

- **强烈建议找专业专利代理机构**撰写：权利要求的措辞极其讲究，一个词的范围差异可能决定专利值不值钱。
- 与代理人沟通时，你要提供清晰的**技术交底书**（讲清背景、要解决的问题、方案、创新点、有益效果、可能的替代方案）——用 [发明专利申请模板](../templates/patent-application-template.md) 起草。

## 八、给科研人的实操建议

- **有产业价值的成果，投稿前先评估专利**。学生也可以是发明人，和导师/学校/单位确认权属与流程。
- **专利 + 论文组合拳**：先申请专利占日，再投论文，两者同源，学术与产权双赢。
- **别在专利里泄光底牌**：说明书公开到能实现即可，最尖端的工程 trick 可以斟酌保留（但要保证权利要求有说明书支持）。

## 本章 Checklist

- [ ] 确认成果值得申请专利，且**未在申请前公开**。
- [ ] 若同时要发论文，已规划好"先专利后论文"的顺序。
- [ ] 独立权利要求只含必要特征，用词上位。
- [ ] 从属权利要求层层兜底，数量足够。
- [ ] 说明书对每个权项特征都有支持性记载。
- [ ] （推荐）已联系专业代理机构，备好技术交底书。
