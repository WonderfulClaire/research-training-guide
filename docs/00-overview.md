# 00 · 科研全流程总览

> 一次科研，从"我想做点什么"到"成果被世界看见"，中间要走完一条完整的流水线。这一章给你全局地图，后面每一章是地图上的一站。

## 一张图看懂科研流程

```
                       ┌─────────────────────────────────────────────┐
                       │                  ① 选题与调研                  │
                       │  读方向 → 找 gap → 提出一个"值得做"的问题       │
                       └───────────────────────┬─────────────────────┘
                                               │  假设（Hypothesis）
                                               ▼
                       ┌─────────────────────────────────────────────┐
                       │                  ② 实验设计                    │
                       │  定 baseline / 数据 / 指标 / 变量 / 消融方案     │
                       └───────────────────────┬─────────────────────┘
                                               │  可复现的实验协议
                                               ▼
                       ┌─────────────────────────────────────────────┐
                       │              ③ 实验执行与迭代                  │
                       │  跑实验 → 记录 → 分析 → 修正假设（可能回到①②）   │
                       └───────────────────────┬─────────────────────┘
                                               │  站得住的结果 + 结论
                                               ▼
             ┌──────────────────────── ④ 成果转化 ────────────────────────┐
             │                                                             │
             ▼                          ▼                                  ▼
   ┌──────────────────┐      ┌──────────────────┐            ┌──────────────────┐
   │   会议论文         │      │   期刊论文         │            │      专利         │
   │ 新想法+初步验证    │      │ 完整系统+充分实验   │            │ 圈定技术独占权     │
   │ 周期短、迭代快     │      │ 周期长、分量重      │            │ ⚠ 必须先于论文公开 │
   └──────────────────┘      └──────────────────┘            └──────────────────┘
             │                          │                                  │
             └──────────────┬───────────┴──────────────┬──────────────────┘
                            ▼                          ▼
                     同行评审 / 审查              录用 / 授权 → 影响力 & 保护
```

**关键点**：这不是一条单向直线。②③ 之间反复迭代很正常；实验结果推翻假设，就回到 ① 重新提问。真正的科研，大部分时间花在这个循环里。

## 三种成果，怎么选

| 维度 | 会议论文 | 期刊论文 | 专利 |
|---|---|---|---|
| **核心目的** | 快速发布新想法 | 系统、完整地论证 | 圈定独占权、防他人使用 |
| **看重什么** | 创新性 + 初步验证 | 完整性 + 充分实验 | 新颖性 + 创造性 + 实用性 |
| **周期** | 短（约 4–6 个月） | 长（半年到两年） | 长（发明专利约 2–3 年授权） |
| **篇幅** | 短（如 ICASSP 4 页） | 长（十几到几十页） | 中（重在权利要求精准） |
| **评价者** | 同行（常双盲） | 同行（多轮） | 专利审查员 |
| **语言取向** | 强调贡献、讲清故事 | 严谨、面面俱到 | 上位、宽泛、留余地 |
| **公开策略** | 越快越好 | 越快越好 | **先占申请日再公开** |

> 三者可以"同源"：同一套技术，论文用来建立学术影响力，专利用来保护。但顺序不能错——见下。

## ⚠️ 最容易毁掉成果的一个坑：公开顺序

**论文一旦公开发表（含 arXiv 预印本、会议录用公开），就会破坏专利的"新颖性"，之后再申请专利会被驳回。**

正确策略二选一：

1. **先专利后论文**：先提交专利申请（哪怕先占一个申请日），拿到申请号后再投稿论文。
2. **用优先权衔接**：在首次申请日起 12 个月内完成后续布局。

如果你的工作有产业价值，动笔投稿前先问自己一句："这个要不要申专利？" 详见 [05 · 专利写作](./05-patent.md)。

## 心态：科研是训练，不是天赋

写不出、跑不通、被拒稿，都是过程的一部分，不是你不行。这份指南把老手们"踩过的坑"提前告诉你，让你把精力花在真正的创新上，而不是在格式、流程、套路上反复摔跤。
